# Проверка Slate RU

Проверено на macOS 27.0, Apple Silicon.

- Проверка синтаксиса JavaScript и 568 записей русского словаря: успешно.
- Русские формы числительных, сообщения об ошибках, настройки отдельной сборки: успешно.
- `pdf_engine_tests`: 12 тестов пройдено.
- `print_label_tests`: 9 тестов пройдено.
- Браузерная проверка: первый запуск с английской локалью даёт русский интерфейс;
  двухстраничный PDF с кириллицей открывается; работают поиск и заметки;
  окно подписи переведено; ошибок JavaScript и обращений к обновлениям оригинала нет.
- Нативная сборка: запуск, открытие документа через русский системный диалог,
  заполнение и сохранение формы с кириллицей, русский системный диалог печати.
- После сохранения PDF прочитан независимо через pypdf: значение поля «Проверка формы»
  и исходный русский текст сохранены, количество страниц — 2.

Физическая печать не выполнялась: принтер не выбран. Подписание реальным сертификатом
и запросы к платным ИИ-сервисам не выполнялись. Они не нужны для проверки перевода.

Установленная копия `/Applications/Slate RU.app`: подпись проверена через codesign,
повторное открытие и экспорт PDF выполнены. Независимая проверка экспортированного
файла подтвердила две страницы, кириллицу и сохранённое значение поля формы.
