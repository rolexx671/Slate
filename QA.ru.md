# Проверка Slate RU

Проверено на macOS 27.0, Apple Silicon.

- Проверка синтаксиса JavaScript и 568 записей русского словаря: успешно.
- Русские формы числительных, сообщения об ошибках, настройки отдельной сборки: успешно.
- `pdf_engine_tests`: 12 тестов пройдено.
- `print_label_tests`: 9 тестов пройдено.
- Браузерная проверка: первый запуск с английской локалью даёт русский интерфейс;
  двухстраничный PDF с кириллицей открывается; работают поиск и заметки;
  окно подписи переведено; ошибок JavaScript и обращений к обновлениям оригинала нет.
- Нативная сборка: запуск, открытие документа через русский системный диалог,
  заполнение и сохранение формы с кириллицей, русский системный диалог печати.
- После сохранения PDF прочитан независимо через pypdf: значение поля «Проверка формы»
  и исходный русский текст сохранены, количество страниц — 2.

Физическая печать не выполнялась: принтер не выбран. Подписание реальным сертификатом
и запросы к платным ИИ-сервисам не выполнялись. Они не нужны для проверки перевода.

Установленная копия `/Applications/Slate RU.app`: подпись проверена через codesign,
повторное открытие и экспорт PDF выполнены. Независимая проверка экспортированного
файла подтвердила две страницы, кириллицу и сохранённое значение поля формы.

## Преобразование (0.3.138-ru.5)

- Шесть Rust-тестов пройдены: сигнатуры JPG/PNG/WebP/TIFF; пиксели и прозрачность
  при сжатии без потерь; белый фон JPG; метаданные разрешения PNG; размер растра
  при 72/150/300 dpi; выбор страниц и TXT; импорт всех четырёх форматов в PDF;
  ошибки для многостраничного TIFF и повреждённых файлов; защита оригинала.
- Браузерная проверка: рабочая вкладка, действия без открытого PDF, четыре формата,
  диапазоны страниц, качество JPG, dpi, отмена и завершение, TXT, извлечение картинок,
  преобразование отдельного изображения; обе темы и окно 800×600. Ошибок JS нет.
- На Mac подтверждена поддержка ru-RU в Apple Vision. Проверены распознавание
  русской фразы на изображении и полный цикл скан → OCR → PDF с извлекаемой
  кириллицей. Для невидимого текстового слоя используется встроенный CID-шрифт
  Liberation Sans с кириллицей. OCR-движок — системный Apple Vision.
- При проверке установленной сборки выявлено ограничение Hardened Runtime:
  ad hoc-приложение не могло загрузить PDFium из-за отсутствия общего Team ID.
  Пользователь явно разрешил исключение library validation только для Slate RU.
  Hardened Runtime оставлен включённым; добавлена проверка SHA-256 конкретной
  ARM64-библиотеки PDFium и отключён поиск произвольной системной PDFium на Mac.
- Отдельный тест проверки целостности принимает закреплённую библиотеку и отвергает
  изменённые/отсутствующие файлы. Реальный тестовый PDF с кириллицей и формой успешно
  преобразуется в PNG 1240×1754 вне ограниченного процесса; финальная установленная
  сборка проходит отдельную проверку после подписи.
- Финальная установленная сборка с разрешённым исключением: PNG успешно сохранён
  из окна приложения (1240×1754 при 150 dpi), TXT содержит корректную кириллицу
  обеих страниц. SHA-256 исходного PDF не изменился. Подпись приложения и закреплённая
  библиотека проверены, Slate RU остался обработчиком PDF по умолчанию.
