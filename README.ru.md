# Slate RU

Русская версия [Slate](https://github.com/Soflutionltd/Slate) для macOS Apple Silicon.
Основа: `adfb0722263365eb8d11b2ffdb1c3e91a9fd7889`. Версия сборки: `0.3.138-ru.5`.

Русский включён при первом запуске независимо от языка macOS. Переведены интерфейс,
подсказки, меню, окна, доступные пользователю сообщения и инструкции ИИ-помощника.
Содержимое PDF, имена файлов и названия шрифтов сохраняются без перевода.

Приложение называется **Slate RU**, идентификатор — `com.rolexx671.slate.ru`.
Оно хранит настройки отдельно от оригинала, не меняет обработчик PDF по умолчанию
и не устанавливает обновления оригинального Slate. Обновления выполняются вручную
путём сборки новой версии этой ветки. Локальная сборка использует разрешённое пользователем исключение проверки подписи
динамических библиотек только для Slate RU. Hardened Runtime остаётся включён.
Перед загрузкой PDFium приложение проверяет SHA-256 закреплённой ARM64-библиотеки;
загрузка произвольной системной PDFium отключена.
Подпись локальная (ad hoc), без нотариального
заверения Apple. Системные окна используют русскую локализацию macOS; названия,
предоставляемые драйвером принтера или внешними сервисами, определяются ими.

## Тема оформления

Тёмная графитовая тема включена по умолчанию. Выбор находится в **Настройки →
Отображение → Тема оформления**, а также **Вид → Тема оформления** в меню macOS.
Доступны тёмная, светлая и системная темы. Настройка сохраняется между запусками и
синхронизируется между окнами; системная тема реагирует на изменения macOS.
Страницы PDF, изображения и подписи сохраняют исходные цвета при просмотре и экспорте.

## Шрифт интерфейса

Системный SF Pro на macOS: основные подписи 14 px / 500 с обычными интервалами,
заголовки панелей 15 px / 600. Размеры согласованы в светлой и тёмной темах.
Правила находятся в `frontend-dist/typography.css`; шрифты PDF и подписей не меняются.

## Разделение PDF

Откройте PDF и выберите **Все инструменты → Разделить PDF**, пункт рядом с
«Объединить файлы» в режиме редактирования или **Файл → Разделить PDF…**.
Введите номера и диапазоны через запятую, например `1-3, 5, 7-10`.
Номера отсчитываются от первой физической страницы файла.

- **Выбранные страницы в один PDF** — объединяет выбранные страницы в порядке оригинала.
- **Каждую страницу в отдельный PDF** — создаёт по одному файлу на выбранную страницу.
- **Каждый диапазон в отдельный PDF** — создаёт отдельный файл для каждого элемента списка.

Для одного результата открывается окно сохранения, для нескольких — выбор папки.
Несколько PDF сохраняются в новую подпапку с уникальным именем. Оригинал остаётся
открытым; разделение не перезаписывает его. Текущие изменения включаются в результат
через обычный механизм экспорта приложения. Неверные номера проверяются до сохранения.

## Преобразование

Вкладка **Преобразовать** содержит:

- PDF в изображения: выбранные страницы в JPG, PNG, WebP или TIFF;
- извлечение встроенных изображений PDF с выбором одного из тех же форматов;
- PDF в TXT: текст выбранных страниц в UTF-8;
- статичные изображения JPG, PNG, WebP и одностраничные TIFF в PDF;
- смена формата отдельного изображения.

Для страниц доступны 72, 150 и 300 dpi, для JPG — качество 75%, 90% и 100%.
PNG, WebP и TIFF используют сжатие без потерь; выходные изображения имеют 8 бит
на канал. Прозрачность сохраняется в этих трёх форматах, а в JPG заменяется белым
фоном. Несколько файлов сохраняются в новую папку с уникальным именем. Исходные
файлы не перезаписываются. Предельный размер растра — 40 мегапикселей, не более
16 000 пикселей по стороне; для больших страниц нужно снизить разрешение.
Анимация и многостраничные TIFF отклоняются с объяснением, чтобы не терять кадры.

TXT извлекает существующий текстовый слой. Для сканов сначала выберите «Распознать скан (OCR)» в разделе «Преобразовать».
Созданный PDF с текстовым слоем открывается автоматически; затем выберите TXT. На Mac используется готовый Apple Vision; русский интерфейс
передаёт русский и английский языки. Проверено на macOS 27. Tesseract предусмотрен
как дополнительный резервный движок, но не поставляется в этой сборке.
Word, Excel и PowerPoint в эту версию преобразования не входят.

## Повторная сборка

Нужны Xcode Command Line Tools, Rust stable и Tauri CLI 2:

```sh
xcode-select --install
# Установите Rust через https://rustup.rs, затем:
cargo install tauri-cli --version '^2' --locked
git clone --branch russian-localization https://github.com/rolexx671/Slate.git
cd Slate
bash scripts/build-ru.sh
```

Сценарий загружает PDFium `chromium/7891`, проверяет SHA-256, собирает Rust-модули
и приложение. Готовый пакет: `src-tauri/target/release/bundle/macos/Slate RU.app`.
Скопируйте его в `/Applications`. Сценарий `scripts/release.sh` относится к оригиналу;
для русской версии используйте только `scripts/build-ru.sh`.

## Проверки

```sh
node --check src-tauri/frontend-dist/app.js
node tests/localization.mjs
node tests/theme.mjs
node tests/page-selection.mjs
ALTO_PDFIUM_DIR="$PWD/src-tauri" cargo test --release --manifest-path src-tauri/Cargo.toml --test pdf_engine_tests --test print_label_tests --test split_pdf_tests --test conversion_tests
```

`ru.js` содержит русский словарь и правила множественного числа. Новые пользовательские
строки добавляйте в словарь и вызывайте через `t()`. Технические идентификаторы команд
и форматов PDF не переводите. Подробности внутренних ошибок остаются в диагностике,
а пользователь получает русское сообщение.
